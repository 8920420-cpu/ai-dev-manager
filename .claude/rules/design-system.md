# Цветовая схема приложений

Эта палитра обязательна для новых фронтендов и при развитии существующих
приложений. Цвет модуля используется как основной брендовый акцент: primary
actions, активная навигация, focus/selection и ключевые индикаторы. Нейтральные
фоны, текст и семантические цвета ошибок/предупреждений не перекрашивать в цвет
модуля.

| Модуль | Цвет | Базовый токен | Смысл | Статус |
|---|---|---:|---|---|
| Продажи | Зелёный | `#16A34A` | Деньги, рост, успех | Сделано |
| ПС Чат | Синий | `#2563EB` | Общение, доверие | Сделано |
| Закупки | Оранжевый | `#EA580C` | Активность, заказ, снабжение | Сделано |
| Склад | Янтарный / коричневый | `#D97706` | Коробки, паллеты, логистика | Запланировано |
| Зарплата и кадры | Фиолетовый | `#7C3AED` | Люди, документы, управление | Запланировано |

## Правила применения

- При старте нового фронтенда сначала определить модуль по этой таблице и
  завести его цвет как семантический токен `--primary`, а не размазывать hex по
  компонентам.
- Производные состояния (`hover`, `active`, `soft`, `border`) строить из той же
  цветовой шкалы с достаточным контрастом; базовый токен соответствует примерно
  оттенку `600` палитры Tailwind.
- Для «Продаж» и «ПС Чата» уже реализованный дизайн является источником истины.
  Если фактический production-токен отличается от указанного базового оттенка,
  сохранять существующий токен и зафиксировать уточнение в этой таблице.
- Цвет модуля не заменяет семантические `success`, `warning`, `danger` и `info`:
  их смысл и контраст должны оставаться одинаковыми во всех приложениях.
- Текст, иконки и элементы управления на цветном фоне должны соответствовать
  WCAG AA по контрасту.
- Соседние по оттенку модули различать нельзя «на глаз»: оранжевый закупок
  (`#EA580C`) и янтарный склада (`#D97706`) стоят рядом, поэтому склад менять на
  оранжевый нельзя — он остаётся `#D97706`.

## Закупки (ПС-Снабжение) — фактические токены

Реализовано во фронте ПС-Снабжения. Значения зафиксированы: это контракт, а не
рекомендация, — те же токены прописаны в CSS приложения.

Светлая тема:

| Токен | Значение | Шкала Tailwind |
|---|---|---|
| `--primary` | `#EA580C` | orange-600 |
| `--primary-hover` | `#C2410C` | orange-700 |
| `--primary-active` | `#9A3412` | orange-800 |
| `--primary-soft` | `rgba(234, 88, 12, 0.16)` | orange-600 @ 16 % |
| `--primary-border` | `rgba(234, 88, 12, 0.38)` | orange-600 @ 38 % |
| `--primary-rgb` | `234 88 12` | каналы `--primary` |

Тёмная тема (на тёмном фоне базовый оттенок сдвигается на шаг светлее, иначе
акцент проваливается в фон):

| Токен | Значение | Шкала Tailwind |
|---|---|---|
| `--primary` | `#F97316` | orange-500 |
| `--primary-hover` | `#FB923C` | orange-400 |
| `--primary-active` | `#EA580C` | orange-600 |
| `--primary-soft` | `rgba(249, 115, 22, 0.20)` | orange-500 @ 20 % |
| `--primary-border` | `rgba(249, 115, 22, 0.42)` | orange-500 @ 42 % |
| `--primary-rgb` | `249 115 22` | каналы `--primary` |

`--primary-rgb` — тот же цвет модуля, разложенный на каналы для произвольной альфы
(`rgb(var(--primary-rgb) / 0.22)`): фиксированных `soft`/`border` не хватает, когда в
интерфейсе десятки тинтов с разной прозрачностью. Значение ОБЯЗАНО совпадать с
`--primary` темы — это не второй цвет, и расходиться они не должны.

### Контраст оранжевого — правило применения

Оранжевый — «низкоконтрастный» цвет на белом, поэтому базовый токен применим не
везде. Посчитанные значения и что из них следует:

- `#EA580C` на белом — **3.56:1**. Это проходит порог `3:1` для нетекстовых
  элементов и крупного текста, но НЕ проходит `4.5:1` для основного текста.
  Значит `--primary` в светлой теме — только заливка, границы, иконки, focus-ring
  и крупные заголовки.
- Мелкий оранжевый текст на светлом фоне (ссылки, подписи, значения) брать из
  `--primary-hover` `#C2410C` — **5.18:1**, проходит WCAG AA.
- Белый текст на заливке `--primary` `#EA580C` — **3.56:1**: допустим только
  крупным начертанием (от 18.66 px bold / 24 px regular). Для кнопок с мелкой
  подписью использовать заливку `#C2410C` (белый на ней — 5.18:1).
- В тёмной теме `#F97316` на тёмном фоне даёт ≈ **6.5:1** — проходит AA и для
  текста, и для элементов управления.
- Проверять контраст обеих тем при любом изменении токенов: сдвиг одного оттенка
  ломает пару «текст на заливке» и «текст на фоне» одновременно.
